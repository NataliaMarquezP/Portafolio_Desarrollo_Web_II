# 🌐 Portafolio Desarrollo Web II

Sitio web desarrollado como proyecto académico para la asignatura **Desarrollo Web II**, enfocado en la creación de una página web personal que presenta información profesional, formación académica, experiencia laboral, habilidades y proyectos realizados.

## 📋 Descripción

Este proyecto corresponde a un portafolio web desarrollado utilizando tecnologías de desarrollo web front-end y Java Web. Su objetivo es mostrar el perfil profesional de la autora y servir como evidencia práctica de los conocimientos adquiridos durante la formación en Ingeniería Informática.

## 🚀 Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- JSP (Java Server Pages)
- Bootstrap 5
- Apache Maven
- Java

## 💻 Instalación y Ejecución

### Clonar el repositorio

```bash
git clone https://github.com/NataliaMarquezP/Portafolio_Desarrollo_Web_II.git
```

### Ingresar al proyecto

```bash
cd Portafolio_Desarrollo_Web_II
```

### Ejecutar mediante Maven

```bash
mvn clean install
```

### Desplegar en un servidor compatible con JSP

Puede ejecutarse utilizando:

- Apache Tomcat
- Eclipse IDE for Enterprise Java
- IntelliJ IDEA Ultimate
- NetBeans
